    Re-rank reuses the analysis already done, so it is instant. The clip length setting in the options sheet fills these numbers.

    AI titles (runs on your device)

    A small AI model writes a new headline instead of reusing a sentence from the video. Text reads the transcript (about 80 MB download once). Text + frames uses a larger title model (about 250 MB once) plus an image-captioning model (about 220 MB once) that looks at two frames per clip so the title fits what is on screen. Switch it on or off per video in the options sheet.

    Speech only

    Detects stretches that sound like music or singing and does not transcribe them, so lyrics do not become clips. It is an estimate from the sound, so it can be wrong on singing that sounds like speech. It also saves time.

    Speech model

    Fast (about 40 MB) is quicker on phones. Balanced (about 80 MB) is more accurate.

    Caption timing

    Fast times each spoken phrase and spreads its words evenly, which transcribes noticeably quicker. Precise times every word: slower, better lip-sync.

    Multi-threading

    Uses several CPU cores for speech when the browser allows it. Turn off if transcription ever freezes, then reload the page.

    Speed: use the GPU for speech

    Auto uses the GPU on computers and the CPU on phones. "Try GPU" can be much faster on a phone, and falls back to the CPU if it fails.

    Notifications

    Shows a system notification when analysis or saving finishes while the app is in the background. Not available in every browser.

    Diagnostics

    If something fails, run this and send a screenshot of the result.
